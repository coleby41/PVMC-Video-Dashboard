Wi-Fi Connection Help

Wi-Fi Connection Instructions

  1. Open your device's Wi-Fi settings.
  2. Select "PVMC Staff" from the available list. If you join "PVMC Congregation" instead, you will not be able to access the dashboard.
  3. Enter the password for the staff network.
  4. Wait a few seconds for the device to connect.
  5. Once connected, you should see a Wi-Fi icon in your device's status bar.
  6. If the popup is still showing "You have left campus," try refreshing the page or restarting your device.
