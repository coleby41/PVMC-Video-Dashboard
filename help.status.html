Browser Network Access Help

Allow Local Network Access

Why is this needed?

The dashboard runs on a local network. Modern browsers require permission to access local devices. Granting access ensures your browser can communicate with the dashboard.

Google Chrome
  1. Click the lock icon in the address bar while on the dashboard site.
  2. Select Site Settings.
  3. Find Local Network Access and set it to Allow.
  4. Refresh the dashboard page.
Safari (Mac / iPhone)
  1. Open Settings (iPhone) or Safari Preferences (Mac).
  2. Go to Privacy & Security → Local Network.
  3. Find the dashboard site and toggle access to Allow.
  4. Reload the dashboard page.
Microsoft Edge
  1. Click the three dots (⋯) → Settings → Cookies and Site Permissions → All Sites.
  2. Find your dashboard URL.
  3. Allow Local Network Access.
  4. Refresh the page.
Mozilla Firefox
  1. Click menu (☰) → Settings → Privacy & Security.
  2. Scroll to Permissions → Local Network Access.
  3. Locate the dashboard site and allow access.
  4. Reload the page.
Still Having Issues?
  • Ensure you are connected to PVMC Staff Wi-Fi.
  • Refresh the dashboard page.
  • Restart your browser if needed.
  • Contact the Dashboard Admin if the issue continues.
